## 📌 Objetivo do Sistema
Este sistema foi desenvolvido para ajudar usuários a estimarem o consumo mensal de energia elétrica de seus aparelhos eletrodomésticos em kilowatt-hora (kWh) e o custo mensal aproximado em reais.

## 🧮 Fórmula Utilizada
O cálculo do consumo mensal é realizado utilizando a seguinte relação:

$$consumoMensal = \frac{potencia \times horasDia \times 30}{1000}$$

* **potencia:** Potência do aparelho em Watts (W)
* **horasDia:** Tempo médio de uso diário em horas
* **30:** Quantidade de dias no mês
* **1000:** Fator de conversão de Watts para Kilowatts (kW)

## 🚀 Como Executar
1. Certifique-se de ter o **Python 3** instalado.
2. Abra o terminal na pasta do projeto e execute:

python app.py
